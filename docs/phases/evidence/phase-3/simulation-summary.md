## 1. How it was run

- **Shares without failures** (the grid of section 14.1): each replicate draws three wordings of
  runs for two objectives on S1's lattice (1/125), and its interval is the **exact** stratified
  percentile bootstrap: the limit, with no Monte Carlo error, of the engine's 100,000-resample
  interval, computed by convolution. Running the engine itself on the grid would take about 240
  hours on one core. Section 5 checks the two against each other. Every verdict is the analysis's
  own `verdict.decide`.
- **Choice rates** are **exact**: the verdict depends only on the two counts, so each rate is a sum
  of binomial probabilities times the analysis's own Newcombe interval and verdict.
- **Failures, the wording rule and the resample count** run the analysis itself, end to end, at its
  frozen settings, on S1 runs built as run rows, and each check is recomputed independently.
- **A run's share** is, with probability pi, all in (1 with probability equal to the mean, else 0),
  and otherwise a Beta draw rounded to the lattice, its mean solved so the mixture's mean is exact.
  sigma is the Beta part's standard deviation. The first objective has the larger mean.
- Every seed is derived from the task's name. Rates from replicates carry a 95% Wilson interval;
  **missed** means the observed rate is over the target, **clearly missed** that the interval's
  lower end is.
